# Как запустить Lead Finder на сервере

Инструкция для человека без опыта в программировании.  
Занимает ~20 минут. Запросы к Checko.ru будут идти с IP сервера, а не с вашего компьютера.

---

## Что нам понадобится

- Аккаунт на [GitHub](https://github.com) (бесплатно)
- Аккаунт на [Railway](https://railway.app) (бесплатно, $5 кредит в месяц)
- Папка с кодом парсера (та, что сейчас на вашем компьютере)

---

## Шаг 1. Загрузить код на GitHub

### 1.1 Создать репозиторий на GitHub

1. Зайди на [github.com](https://github.com) → войди в аккаунт
2. Нажми зелёную кнопку **New** (или **+** → New repository)
3. Название: `lead-finder` (или любое другое)
4. Выбери **Private** (приватный — важно, чтобы код не был публичным)
5. Нажми **Create repository**

### 1.2 Создать файл .gitignore

Перед загрузкой нужно убедиться, что `.env` (с паролями) не попадёт в GitHub.

Создай в папке парсера файл `.gitignore` со следующим содержимым (если он уже есть — просто проверь, что эти строки там есть):

```
.env
__pycache__/
*.pyc
*.log
pipeline.log
lead_finder_state.json
tg_profile/
backups/
```

### 1.3 Загрузить папку

Открой **Терминал** (на Mac: Spotlight → Terminal) и выполни по очереди:

```bash
cd /Users/medyumedbluewaters/parser

git init
git add .
git status   # убедись, что .env НЕ показан в списке
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/lead-finder.git
git push -u origin main
```

⚠️ Замени `ВАШ_ЛОГИН` на свой логин GitHub.

GitHub спросит логин и пароль — введи данные своего GitHub-аккаунта.

---

## Шаг 2. Развернуть на Railway

### 2.1 Создать проект

1. Зайди на [railway.app](https://railway.app) → **Login with GitHub**
2. Нажми **New Project**
3. Выбери **Deploy from GitHub repo**
4. Найди репозиторий `lead-finder` → нажми **Deploy Now**

Railway автоматически найдёт `Dockerfile` и начнёт сборку. Это займёт **5–10 минут** (скачивается Chromium).

### 2.2 Настроить переменные окружения

Пока идёт сборка:

1. В Railway кликни на свой сервис → вкладка **Variables**
2. Нажми **Add Variable** и добавь по одной:

| Название | Значение |
|----------|----------|
| `APP_PASSWORD` | придумай пароль для входа в интерфейс |
| `BRIZO_URL` | `https://sad1.brizo.ru` |

> Логин и пароль от Brizo ты вводишь прямо на странице входа — они не хранятся на сервере постоянно.

### 2.3 Получить ссылку

1. После успешной сборки → вкладка **Settings** → раздел **Networking**
2. Нажми **Generate Domain** — Railway выдаст адрес вида `lead-finder-xxx.railway.app`
3. Открой этот адрес в браузере — должна появиться страница входа

**Готово!** Теперь парсер доступен с любого устройства.

---

## Альтернатива: Render.com

Если Railway не подходит:

1. Зайди на [render.com](https://render.com) → **Sign up with GitHub**
2. **New** → **Web Service**
3. Выбери репозиторий `lead-finder`
4. Настройки:
   - **Environment**: Docker
   - **Instance Type**: Free (или Starter за $7/мес если Free не хватает памяти)
5. В разделе **Environment Variables** добавь те же переменные что на Railway
6. Нажми **Create Web Service**

⚠️ На Render бесплатный план засыпает через 15 минут неактивности.  
При первом открытии страница загружается ~30 секунд (сервер просыпается).  
Во время работы парсера он не засыпает.

---

## Шаг 3. Первый запуск

1. Открой ссылку сервиса в браузере
2. Введи **логин и пароль от Brizo** (те же что используешь на brizo.ru)
3. Настрой параметры поиска → нажми **Запустить поиск**
4. Следи за прогрессом в реальном времени

Запросы к Checko.ru теперь идут с IP сервера в Европе/США.

## Обновление кода

Когда нужно обновить код (например, после изменений):

```bash
cd /Users/medyumedbluewaters/parser
git add .
git commit -m "Обновление"
git push
```

Railway автоматически пересоберёт и перезапустит сервис.

---

## Важно

- Файл `.env` **никогда не загружается** в GitHub — пароли безопасны
- Состояние прогресса (`lead_finder_state.json`) сбрасывается при каждом деплое
- Proxies из `proxies.txt` работают и на сервере

---

## Если что-то пошло не так

**Сборка упала** → в Railway/Render смотри вкладку **Logs** → ищи красные строки с ошибкой

**Сайт не открывается** → проверь что в **Settings → Networking** есть домен и порт 8082 открыт

**Не хватает памяти (OOM)** → перейди на платный план Railway ($5/мес) или Render Starter ($7/мес)
